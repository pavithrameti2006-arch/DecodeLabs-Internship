# Rule-Based AI Chatbot 🤖

## Project Overview
This project is a simple conversational chatbot developed
using Python. It responds to user messages using predefined
rules and conditional statements.

## Objectives
- Handle greetings and exit commands.
- Respond to basic questions.
- Use if-elif-else decision-making logic.
- Maintain continuous conversations using a loop.
- Handle unknown inputs with a default response.

## Technologies Used
- Python 3.13
- Visual Studio Code

## Features
- Greeting responses
- Chatbot introduction
- Basic AI and Python explanations
- Help command
- Thank-you responses
- Unknown-input handling
- Continuous conversation
- Exit functionality

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python chatbot.py

## Python Concepts Used
- Variables
- User input and output
- String manipulation
- If-elif-else statements
- While loop
- Break statement

## Limitations
This chatbot uses predefined rules and does not
learn from conversations or understand complex language.

## Future Improvements
- Add more predefined responses.
- Save conversation history.
- Integrate Natural Language Processing.

## Conclusion
This project demonstrates the fundamentals of a
rule-based conversational system using Python.
